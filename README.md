# CustomWin

Лёгкая программа для кастомизации интерфейса Windows 10/11: глубокие настройки, готовые пресеты и **ваши обои на фоне окон и меню**.

Написана на C# / .NET 8 (WinForms). Живёт в трее, окно настроек создаётся только когда вы его открываете. Права администратора не нужны, в чужие процессы ничего не внедряется.

## Возможности

| Раздел | Что можно настроить |
|---|---|
| **Пресеты** | 8 готовых тем («Тёмный минимализм», «Светлый воздух», «Неон», «Стекло», «Закат», «Ретро», «Производительность», «Стандарт Windows»), свои пресеты, импорт/экспорт `.json`, превью |
| **Тема и цвета** | светлая/тёмная тема отдельно для приложений и системы, акцентный цвет, акцент на заголовках и панели задач, прозрачность |
| **Окна** | тёмный/светлый заголовок, цвет заголовка, текста и рамки, форма углов, Mica / Акрил / Mica Alt, полупрозрачность всех окон, исключения по процессам |
| **Фон за окнами и меню** | картинка (своя, обои рабочего стола или градиент) внутри активного окна и классических меню; размытие, затемнение, оттенок, два режима расположения |
| **Обои** | картинка, сгенерированный градиент, слайд-шоу из папки |
| **Панель задач и Проводник** | выравнивание значков, «Представление задач», поиск, классическое контекстное меню, расширения и скрытые файлы, анимации, задержка меню |

## Как работает «фон за окнами и меню»

Windows не даёт поставить картинку фоном в чужие окна и меню. CustomWin делает это снаружи:

1. Позади активного окна (или открытого меню) ставится подложка — невидимое для мыши окно с вашей картинкой ровно по его границам.
2. Само окно становится полупрозрачным (`WS_EX_LAYERED`), и картинка видна сквозь него.
3. Подложка следит за перемещением, сворачиванием и сменой активного окна через системные события (`SetWinEventHook`).

В режиме «Закреплена на экране» окно работает как окошко в общую картинку: при перетаскивании видна соответствующая часть изображения.

## Ограничения (честно)

- **Меню «Пуск», центр уведомлений и новое контекстное меню Windows 11** — это XAML-оболочка, подложка к ним не применяется. Там ваши обои видны через системный акрил («Эффекты прозрачности»). Для контекстного меню Проводника включите «Классическое контекстное меню» — тогда фон работает и там.
- Настоящая картинка внутри «Пуска»/панели задач возможна только модами, которые внедряются в `explorer.exe` (например, Windhawk со стилями *Start Menu Styler* / *Taskbar Styler*). CustomWin сознательно этого не делает.
- Цвета заголовка/рамки и углы работают в Windows 11, Mica/Акрил — с 22H2. В Windows 10 доступны тема, акцент, тёмный заголовок, прозрачность и фон за окнами.
- Приложения со своим заголовком (браузеры, VS Code, Office) могут игнорировать цвет заголовка.
- Окна, запущенные от администратора, недоступны из обычной программы.
- Игры и программы с аппаратным ускорением могут мигать при полупрозрачности — добавьте их в исключения.
- Акцентный цвет и часть настроек панели задач применяются после перезапуска Проводника (кнопка в программе).

## Скачать и запустить

Готовые `.exe` собираются автоматически в GitHub Actions (вкладка **Actions → Build → Artifacts**):

- **CustomWin-lite-win-x64** — маленький файл, нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0);
- **CustomWin-standalone-win-x64** — ничего ставить не нужно, файл больше.

Если поставить тег `v*` (например `v0.1.0`), архивы появятся в Releases.

Параметры запуска:

```
CustomWin.exe --tray              запуск свернутым в трей (так работает автозапуск)
CustomWin.exe --preset "Неон"     применить пресет при запуске
```

Настройки и ваши пресеты хранятся в `%AppData%\CustomWin`. Портативный режим: положите рядом с `CustomWin.exe` пустой файл `portable.txt`.

## Сборка из исходников

```
dotnet build src/CustomWin/CustomWin.csproj -c Release
dotnet publish src/CustomWin/CustomWin.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

## Структура

```
src/CustomWin/
  Program.cs             точка входа, один экземпляр
  Native/Win32.cs        WinAPI / DWM
  Core/Profile.cs        модель настроек (она же формат пресета)
  Core/BuiltInPresets.cs готовые пресеты
  Core/SystemTweaks.cs   тема, акцент, панель задач, Проводник (реестр HKCU)
  Core/WindowStyler.cs   оформление чужих окон через DWM
  Core/BackdropManager.cs фон за окнами и меню
  Core/WallpaperService.cs обои, градиенты, слайд-шоу
  Core/Customizer.cs     ядро и системные события
  UI/                    трей, окно настроек, превью пресетов
```

## Как вернуть всё назад

Выберите пресет **«Стандарт Windows»**. При выходе из программы все окна возвращаются к исходному виду автоматически.
